# BitradeXでKYC（本人確認）を行う手順

## 前提

- BitradeXのアカウント開設が終了していること
- スマートフォンにBitradeXのアプリをインストールし、ログイン済みであること
- カメラ機能が使えるスマートフォンであること
- 運転免許証またはパスポートを所持していること

## KYCの手順

1. BitradeXのホーム画面を開く
2. 画面左上の<strong>人型アイコン</strong>をタップする
3. 表示された<strong>自分のメールアドレス</strong>をタップする
4. <strong>「KYC」</strong>をタップする
5. 運転免許証またはパスポートを使用して、画面の案内に沿って本人確認を行う
