# Trust WalletのSRPをバックアップする手順

SRP（Secret Recovery Phrase／シークレットリカバリーフレーズ）は、端末の紛失や故障などが起きたときに、ウォレットを復元するための重要な情報です。

> [!CAUTION]
> SRPを知っている人は、ウォレット内の資産を操作できる可能性があります。<strong>誰にも教えないでください。</strong>Trust WalletのサポートがSRPを尋ねることもありません。

## 事前準備

バックアップを始める前に、次のものを準備してください。

- Trust Walletをインストール済みのスマートフォン
- 紙とペン
- 画面を他人に見られない安全な場所

## バックアップ手順

1. Trust Walletを開く
2. 画面左上の<strong>「メインウォレット」</strong>をタップする
3. バックアップするウォレットの右側にある<strong>縦の3点アイコン</strong>をタップする
4. バックアップ方法から<strong>「手動」</strong>をタップする
5. 画面に表示される注意事項を確認し、案内に沿って認証を行う
6. 表示されたSRPを、<strong>単語の順番とスペルを変えずに</strong>紙へ書き写す
7. 書き写した内容を画面と照合し、間違いがないことを確認する
8. 画面の案内に沿ってバックアップを完了する

> [!NOTE]
> アプリのバージョンや端末によって、ボタン名や画面の表示が異なる場合があります。

## SRPの安全な保管方法

### やること

- 紙に正確に記録し、鍵のかかる場所などで保管する
- 紛失や災害に備える場合は、複数の紙に記録して別々の安全な場所へ保管する
- 保管後も、単語の順番とスペルが読み取れる状態か確認する

### やってはいけないこと

- スクリーンショットや写真を撮る
- メール、メモアプリ、クラウドストレージへ保存する
- SNSやメッセージアプリで送信する
- 他人やサポート担当者を名乗る人へ教える
- 信頼できないWebサイトやアプリへ入力する

> [!IMPORTANT]
> SRPを紛失すると、端末の故障や紛失時にウォレットを復元できなくなる可能性があります。SRPが他人に知られた場合は、新しいウォレットを作成し、資産を速やかに移してください。
