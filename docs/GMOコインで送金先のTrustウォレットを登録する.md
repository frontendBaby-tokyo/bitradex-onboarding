# GMOコインでTrust WalletをXRPの送付先に登録する手順

GMOコインから自分のTrust WalletへXRPを送るには、事前にTrust Walletの受取アドレスをGMOコインの<strong>「宛先リスト」</strong>へ登録します。

> [!CAUTION]
> 暗号資産は、誤ったアドレスへ送ると取り戻せない可能性があります。アドレスを手入力せず、必ずコピー＆ペーストしてください。登録を確定する前に、貼り付けたアドレスがTrust Walletの表示と一致していることも確認しましょう。

## 事前準備

登録を始める前に、次の準備が完了していることを確認してください。

- GMOコインの口座を開設し、スマホアプリにログインできる
- Trust Walletを作成し、シークレットリカバリーフレーズをバックアップしている
- Trust WalletですでにXRPの残高がある

## 登録の流れ

1. Trust WalletでXRPの受取アドレスを確認する
2. GMOコインの宛先リストへ登録する

## 1. Trust WalletでXRPの受取アドレスを確認する

1. Trust Walletを開く
2. <strong>「受信」</strong>をタップする
3. 検索欄に「XRP」と入力する
4. 表示された<strong>XRP</strong>をタップする
5. XRPの受取画面に表示された<strong>受取アドレス</strong>をコピーする

> [!IMPORTANT]
> XRPの送付では、送付先によって宛先タグ（Destination Tag）が必要な場合があります。Trust Walletの受取画面に表示される情報を確認し、必要性が不明な場合は登録や送付を進めないでください。宛先タグを推測して入力してはいけません。

## 2. GMOコインの宛先リストへ登録する

1. GMOコインへログインする
2. <strong>「入出金」</strong>から<strong>「暗号資産」</strong>を開く
3. <strong>「宛先リスト」</strong>を開く
4. 暗号資産の一覧から<strong>XRP</strong>を選択する
5. <strong>「新しい宛先を追加する」</strong>を選択する
6. 送付先として<strong>「GMOコイン以外」</strong>を選択する
7. 送付先ウォレットとして<strong>「プライベートウォレット」</strong>を選択する
8. 受取人として<strong>「ご本人さま」</strong>を選択する
9. 画面の案内に沿って、宛先情報を入力する

### 主な入力内容

| 項目 | 入力・選択する内容 |
| --- | --- |
| 宛先名称 | 自分で判別しやすい名前（例：Trust Wallet） |
| XRPアドレス | Trust WalletでコピーしたXRPの受取アドレス |
| 宛先タグ | Trust Walletの受取画面とGMOコインの案内に従う |
| 受取人 | ご本人さま |
| 受取人情報 | GMOコインに登録している自分の情報 |

> [!NOTE]
> 選択内容や登録状況によって、実際に表示される入力項目が異なる場合があります。画面に追加項目が表示された場合は、案内に沿って入力してください。

## 3. 入力内容を確認して登録する

1. XRPアドレスがTrust Walletの表示と一致しているか確認する
2. 送付先が<strong>「GMOコイン以外」</strong>になっていることを確認する
3. 送付先ウォレットが<strong>「プライベートウォレット」</strong>になっていることを確認する
4. 受取人が<strong>「ご本人さま」</strong>になっていることを確認する
5. <strong>「確認画面へ」</strong>を選択する
6. 登録内容に誤りがなければ、<strong>「登録」</strong>を選択する
