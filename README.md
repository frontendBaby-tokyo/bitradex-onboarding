# BitradeXオンボーディングガイド

このリポジトリでは、国内取引所のGMOコインでXRPを購入し、Trust Walletを経由してBitradeXへ送金するまでの流れを説明します。

```text
GMOコイン  →  Trust Wallet  →  BitradeX
  XRP購入        一時保管          入金
```

> [!IMPORTANT]
> この資料は、各サービスの操作を補助するための非公式ガイドです。画面や仕様は変更される場合があるため、操作時は必ず各サービスの公式情報と実際の画面も確認してください。

## まずは全体像を学ぶ

細かな画面操作を始める前に、まずはスライド資料で<strong>送金の全体像と安全に判断するための考え方</strong>を確認することをおすすめします。

### スライド資料「日本円から海外取引所へXRPを送る」

- [スライドで見る（PDF・全28ページ）](https://github.com/frontendBaby-tokyo/send-crypto-to-overseas-exchange/blob/master/slides-preview.pdf)

このスライドでは、次の内容を初心者向けに説明しています。

- GMOコイン → Trust Wallet → 海外取引所という送金経路
- GMOコイン、自己管理ウォレット、海外取引所それぞれの役割
- XRP Ledger、受取アドレス、宛先タグを確認する理由
- テスト送付を行ってから本番分を送る考え方
- 海外取引所を利用するメリットとリスク
- 送付を止めるべき状況と、実行前の最終チェック

> [!TIP]
> <strong>スライド資料では「なぜ確認するのか」「何を判断するのか」</strong>を学び、<strong>このリポジトリの各ガイドでは「実際にどう操作するのか」</strong>を確認してください。先に考え方を理解しておくと、アプリの画面が変わっても落ち着いて判断しやすくなります。

## このガイドで行うこと

1. BitradeXでKYC（本人確認）を行う
2. Trust WalletのSRPをバックアップする
3. GMOコインにTrust WalletのXRP受取アドレスを登録する
4. GMOコインでXRPを購入する
5. GMOコインからTrust WalletへXRPを送金する
6. Trust WalletからBitradeXへXRPを送金する

## 推奨する作業順

### 1. BitradeXでKYCを行う

送金を始める前に、BitradeXで本人確認を済ませます。

→ [BitradeXでKYC（本人確認）を行う手順](docs/KYC.md)

### 2. Trust WalletのSRPをバックアップする

Trust Walletを復元するために必要なSRP（シークレットリカバリーフレーズ）を、安全な場所へ保管します。

→ [Trust WalletのSRPをバックアップする手順](docs/TrustのSRPバックアップ.md)

### 3. GMOコインにTrust Walletを登録する

GMOコインからXRPを送れるように、Trust Walletの受取アドレスを宛先リストへ登録します。

→ [GMOコインでTrust WalletをXRPの送付先に登録する手順](docs/GMOコインで送金先のTrustウォレットを登録する.md)

### 4. GMOコインでXRPを購入する

GMOコインの取引所（現物）を利用してXRPを購入します。

→ [GMOコインでXRPを購入する手順](docs/GMOコインでXRPを購入する.md)

### 5. GMOコインからTrust WalletへXRPを送金する

登録した宛先を選び、GMOコインからTrust WalletへXRPを送金します。

### 6. Trust WalletからBitradeXへXRPを送金する

BitradeXで入金情報を確認し、Trust WalletからXRPを送金します。着金後は、BitradeXの資産画面で残高を確認します。

→ [Trust WalletからBitradeXにXRPを送金する手順](docs/TrustからBitradeXにXRPを送金する.md)

## 送金前の重要チェック

- [ ] 送付元と送付先のネットワークが一致している
- [ ] XRPの受取アドレスをコピー＆ペーストしている
- [ ] 貼り付けたアドレスの先頭と末尾が正しい
- [ ] 宛先タグやMEMOの要否を送付先画面で確認している
- [ ] 送金数量と手数料を確認している
- [ ] 初めての宛先では、少額でのテスト送金を検討している

> [!CAUTION]
> 受取アドレス、ネットワーク、宛先タグなどを誤ると、送金したXRPを取り戻せない可能性があります。内容に不明点がある場合は、送金を確定せずに各サービスの公式サポートへ確認してください。

## SRPの取り扱い

SRPは、Trust Wallet内の資産を復元するための重要な情報です。

- 紙などのオフライン環境で安全に保管する
- スクリーンショットや写真を撮らない
- メール、クラウドストレージ、SNSへ保存・送信しない
- 家族、友人、サポート担当者を含め、誰にも教えない

> [!WARNING]
> Trust Walletや正規のサポート担当者がSRPを尋ねることはありません。SRPの入力を求めるメッセージやWebサイトには十分注意してください。
